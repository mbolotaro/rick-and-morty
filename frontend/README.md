# PickleVerso Web

Frontend Next.js do PickleVerso.

## Executar localmente

Com o backend disponível em `http://localhost:3040`:

```bash
cp .env.example .env.local
npm install
npm run dev
```

No PowerShell, substitua o primeiro comando por:

```powershell
Copy-Item .env.example .env.local
```

Abra `http://localhost:3000`.

Consulte o [README principal](../README.md) para a configuração completa do banco, backend e frontend.
